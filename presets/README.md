# WideSmearNT16 presets

16 starting points for WideSmearNT on disting NT. Turn drums, plucks and sustained sounds into smeared attacks, shifting colour and resonant textures.

- **01–06:** increasing phase depth, from short smears to longer tails.
- **07–11:** different frequency ranges and tonal colours.
- **12–13:** blended phase layers for extra colour.
- **14–16:** resonant textures and increasing feedback.

Download the MicroSD ZIP from the [latest release](https://github.com/kf4u43D/WideSmearNT/releases/latest). Copy its `programs/plug-ins/` and `presets/WideSmearNT16/` folders to the same locations on your MicroSD, then restart disting NT and load a preset.

If updating from SmearNT, remove `smearnt_nt.o` from `/programs/plug-ins/` first.

Connect stereo audio to physical inputs **1/2** and listen on physical outputs **1/2**. For mono, set **In R** to **1**. These are complete NT presets; loading one replaces the current setup.

Try a drum loop or plucked sound, then slowly adjust Frequency, Stages and Distribution. Start with moderate levels and feedback, especially with presets 14–16.
